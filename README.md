# Motor Tech Dashboard

Dashboard modern yang menampilkan dua halaman web yang Anda minta dalam satu tampilan: 

- Benyamin Batu Motorcycle Tech AI Force
- Kamus TSMJ Ocular

## Cara membuka

Buka file `index.html` di browser, atau aktifkan GitHub Pages untuk repo ini.

## Deploy ke GitHub Pages

1. Buka repository di GitHub
2. Klik `Settings` > `Pages`
3. Source: `Deploy from a branch`
4. Branch: `main` / `root`
5. Simpan
